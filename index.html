📖 HOW TO PLAY

Select a game below to start playing! All games are playable directly in your browser. Use the controls shown in each game to play. Some games support online multiplayer — where they do, enter the same room code as your friends to land in the same game together.

👥 GROUP PLAY

Enter a name and a room code to see who else is here and stay grouped with them as you move between games. Leave the room code blank to play solo — see the note at the end of this page for what that means.

⚠ Leaving this blank puts you in the shared public room along with anyone else who also left it blank — not private to your group. For a group session, agree on a code with your friends first.
