RD Curves — squelch & morph lab

Contour rendering instead of per-cell discs. Tests whether a coarser network field can still look smooth, and fills the gap between updates with motion.

Surface
Network field (what the host would send)

1 bit gives you no sub-cell values to interpolate, so contours collapse to 45° chamfers. Multi-bit at lower resolution is usually both cheaper and smoother.

Morph between updates

Morph duration is locked to the update interval, so the surface finishes arriving exactly as the next packet lands.

Squelch (render-only)

Domain warp and threshold breathing are applied at draw time only. Collision would still read the raw field, so none of this has to be agreed between clients.
